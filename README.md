One absurd terms-of-service clause: a numbered section granting the Company a perpetual, royalty-free license to the User's dreams — including the right to replay them as advertisements during REM sleep.

## Run it

```sh
node main.ts
```

The program writes the clause to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
